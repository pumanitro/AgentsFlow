      Screen space is what the folded panel takes when nothing is waiting. Interruption is on a 1 (quiet) to 5 (takes over the screen) scale.

      How it would be built (for the engineer)

      Shared story: a routine's chat calls a new notify tool; the main process stores the notice in notifications.json, pushes it to the window and raises a macOS banner for warn/action. Answers go back into the source chat as one message. Full details: the shared plan.

      What this design adds:

      • renderer/components/notifications/NeedsYouPane.tsx — passed to DockedPanes as a new first slot. The height budget in components/DockedPanes.tsx treats it like Accounts: it can shrink, but its header is never dropped. Auto-expands and runs a 2× pulse (CSS keyframes) when a new action arrives; info rows unmount after 6 000 ms with a CSS scale bar; warn rows carry ✕ → dismissNotification(id).
      • renderer/components/notifications/ActionSheet.tsx — a HelpModal-style modal (720 px) mounted once in _app.tsx, opened by id. Left stepper: File → Q1…Qn → To-do → Done; yes/no and choice answers advance by themselves after 350 ms; text needs Next. Done step: “Send answers to the agent” (sendNotificationAnswers), then “Mark done & dismiss”, disabled until canDismiss(n) && n.answersSentAt; its tooltip lists what is missing.
      • renderer/components/routines/NeedsYouChip.tsx — rendered at the left of the RoutinesView toolbar while any action is open; click → switch to Chat view and open the sheet.
      • Persistence beyond the shared shape: answers are saved as typed (answerNotificationQuestion per change, answeredAt each), file opens stamp files[i].openedAt, and the sheet's current step is lastStep on the notice, so closing and reopening resumes exactly.
      • The folded panel stays visible when the list is empty (“all clear”): 42 px of idle height. Hiding it entirely is a one-line option.
